# WRJA Mobile UI

This native Android Studio project replicates the presentation layer of the supplied WRJA React website. It has no backend, authentication, database, image assets, or network requirements.

## Open and run

1. Open the `android-app` folder in Android Studio.
2. Allow Android Studio to complete the Gradle sync.
3. Choose an Android emulator or connected device and press **Run**.

The app opens on the Login screen. The login and account-creation buttons only move through the UI; no user data is stored. The hamburger menu provides Home, About, Events, Programs, News, Gallery, and Contact display screens.

## Design mapping

- Charcoal navigation and hero surfaces: `#161616`
- WRJA gold actions and highlights: `#c9a227`
- White cards on a soft-grey background
- A compact text brand mark is used until the website logo and photos are added
