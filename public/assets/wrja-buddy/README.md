# WRJA Buddy sprite sheets

This folder includes five transparent 32-bit-style starter strips for the preview: `idle.png`, `walk.png`, `run.png`, `jump.png`, and `wave.png`. They can be replaced with final WRJA-approved transparent single-row PNGs, with equal-sized and consistently aligned frames. The supplied labeled concept board is not a production-ready sprite sheet. See the package README for frame-count configuration.
